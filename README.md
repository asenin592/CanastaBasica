# Canasta Basica
Proyecto Integrador — Equipo 2 | Administración de Bases de Datos Corporativas

## Contenido del repositorio

| Archivo | Descripción |
|---|---|
| `Canasta Básica - Presentación.pdf` | Presentación del proyecto |
| `Marco Teorico - Canasta Basica.pdf` | Documentación y marco teórico |
| `implementacion bd.zip` | Código fuente e implementación de la base de datos |

## Descripción

Este proyecto aborda el análisis y gestión de una base de datos corporativa  
enfocada en el seguimiento de la **Canasta Básica**. Incluye el diseño,  
implementación y documentación de la base de datos desarrollada a lo largo del curso.
